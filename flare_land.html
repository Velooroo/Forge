Features

Not just git hosting.
A full dev platform.

Forge combines repository management, a browser IDE, and containerized workspaces into one seamless experience.

🔀

Structured Git Diff API

Compare branches, commits, or tags with a single API call. Get per-file stats (insertions, deletions), detect renames and binary files, filter by path — all parsed from --numstat and --name-status for rock-solid reliability.

CodeMirror 6 Editor

Full-featured in-browser editor with syntax highlighting, multi-cursor, Vim mode, and autocomplete. Not a toy — a real dev tool.

⚡

Docker Workspaces

Every project gets an isolated container. Real terminal, real filesystem, real processes. Spin up in under 2 seconds.

🔥

Git as Persistence

Every file save is a commit. Every branch is a workspace. Your code lives in git — no proprietary lock-in. Clone anywhere.

🔐

Argon2 + JWT Auth

Secure password hashing with Argon2, token-based API access with JWT, and Basic Auth for git operations. Enterprise-grade security.

🧩

Smart HTTP Git

Clone and push over HTTP. No SSH keys to manage. Works behind corporate proxies and firewalls out of the box.

🔄

Optimistic Locking

SHA-based conflict detection on every file write. No silent overwrites — if someone changed the file, you'll know before committing.
